# AI Object Remover

A Flask-based object removal application.

## Features
- Upload image
- Draw mask over object
- Save mask
- Remove object using OpenCV Inpainting
- View processed result

## Technologies
- Python
- Flask
- OpenCV
- HTML/CSS/JavaScript

## Future Improvements
- LaMa AI Inpainting
- Stable Diffusion Inpainting
- Better brush tools
- Download result
